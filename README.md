# NIIB Lucknow — Final website package (B&WSSC marquee)

This update preserves the existing landing page design and inserts the fifth B&WSSC graphic in **both repeating halves** of the scrolling accreditation strip. The four prior logos remain and the marquee loops smoothly. The provided image is embedded in `index.html`, so it will display without external image URLs.

## Included
- `index.html` — complete landing page
- `privacy-policy.html` — standalone privacy policy draft
- `terms-and-conditions.html` — standalone terms draft
- `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`, `vercel.json`
- `assets/bwssc-logo.webp` — reference copy of supplied logo

## Deployment
Upload all files at the **repository root**; do not upload the enclosing folder. Commit to main. Vercel redeploys the connected project. Confirm `/privacy-policy.html`, `/terms-and-conditions.html`, and `/sitemap.xml` resolve directly.

## Before publishing / running ads
1. Client must verify permission to display all accreditation/affiliation logos, including B&WSSC, and confirm the exact relationship. A logo alone does not establish NIIB's certification.
2. Both legal pages are **drafts requiring NIIB review**. Fill in the real data processor, purpose, consent, retention and contact details before enabling lead capture.
3. The enquiry form is not connected to a backend: connect and test it before driving paid traffic.
4. Verify image usage rights and the claims in the uploaded student testimonial creatives.
5. If the public site is not at `https://niiblucknow.com/`, update all canonical and sitemap URLs.
